# Отчёт по Занятию 3: NLP. Классическая векторизация

## 1. Корпус и предобработка

- **Размер корпуса:** 200 вакансий (сгенерированы на основе 15 реальных, для учебных целей).
- **Обучающая часть:** 160 документов (80%).
- **Проверочная часть:** 40 документов (20%).
- **Предобработка:** 6 шагов (нижний регистр, пунктуация, разбиение, отсечение коротких слов, стоп-слова, стемминг).
- **Стоп-слова:** базовый список + 20 слов области (компания, работа, задача, требование и т.д.).

## 2. Паспорт словаря

| Параметр | Значение |
| :--- | :--- |
| Размер корпуса | 160 документов (обучающая часть) |
| На чём построен словарь | Только обучающая часть |
| Размер словаря до отсечения | 565 слов |
| Правило отсечения | `min_df=2` (слово встречается минимум в 2 документах) |
| Размер словаря после отсечения | 565 слов (отсечение не дало эффекта из-за синтетического корпуса) |
| Доля незнакомых слов в проверочной части | 0.0% (все тестовые вакансии — вариации обучающих) |

## 3. Сравнение четырёх решений

| Метод | Precision | Recall | F1 | Комментарий |
| :--- | :--- | :--- | :--- | :--- |
| Балл из Занятия 1 | 0.00 | 0.00 | **0.00** | Порог 0.3 не сработал, модель всех отклонила |
| Признаки из Занятия 2 | 0.45 | 0.67 | **0.54** | Лучший результат, но только из-за синтетических данных (длина текста коррелирует с классом) |

## 4. Разбор двух пар

### Пара с самой высокой близостью (0.2307)
- **Резюме:** Ольга Петрова (маркетолог).
- **Вакансия:** Аналитик (требуется Excel, Google-таблицы).
- **Топ-слова:** `google` (0.1187), `таблицы` (0.0819), `данных` (0.0155), `excel` (0.0146).
- **Почему высоко:** Совпали слова `google` и `таблицы`. Но в резюме `google` — это Google Analytics, а в вакансии — Google-таблицы. Алгоритм не различает контекст.

### Пара с самой низкой близостью (0.0000)
- **Резюме:** Мария Ковалева (сильное, но без ключевых терминов).
- **Вакансия:** Финансовый аналитик.
- **Топ-слова:** (нет общих слов).
- **Почему низко:** Резюме написано «другими словами» (анализ информации, большие массивы данных), а вакансия требует конкретные термины (Excel, Google Sheets). Алгоритм не понимает синонимы.

## 5. Граница метода (синонимы)

Алгоритм на основе TF-IDF не понимает синонимы и перефразирование. Примеры пар, где близость не поймала совпадение:
1. **«анализ информации»** (резюме) vs **«аналитика»** (вакансия).
2. **«большие массивы данных»** (резюме) vs **«работа с большими объёмами данных»** (вакансия).
3. **«визуализировать результаты»** (резюме) vs **«дашборды»** (вакансия).

**Вывод:** Метод работает только на точном совпадении слов. Для понимания смысла нужны эмбеддинги (Word2Vec, трансформеры), которые будут в следующем занятии.
