# CV Matcher: AI-сервис сравнения резюме и вакансий

Этот проект — полный пайплайн от простого подсчета слов до AI-агента с ранжированием вакансий и проверкой на справедливость (fairness).

## 🚀 Что реализовано

*   **Занятие 1:** Базовый подсчет соответствия (пересечение слов, скалярное произведение).
*   **Занятие 2:** ML-модель на признаках (логистическая регрессия, метрики Precision/Recall/F1).
*   **Занятие 3:** Классическая векторизация (TF-IDF, CountVectorizer, косинусная близость).
*   **Занятие 4:** Нейросетевые эмбеддинги (Sentence Transformers, поиск ближайших).
*   **Занятие 5:** AI-агент с RAG (рекомендации на основе LLM, обработка ошибок, валидация).
*   **Занятие 6:** Ранжирование вакансий (NDCG@5, калибровка, fairness-анализ, решение о выпуске).

## 📂 Структура проекта

*   `data/` — вакансии (JSON), резюме (TXT), эмбеддинги, таблицы.
*   `src/` — весь Python-код (загрузка, обработка, модели, агент).
*   `report.md`, `final_report.md`, `release_decision.md` — отчёты по этапам.

## 🛠️ Как запустить

1.  Установите зависимости: `pip install -r requirements.txt`
2.  Запустите основной скрипт: `python src/main.py`
3.  Для проверки агента: `python src/llm_agent.py`
